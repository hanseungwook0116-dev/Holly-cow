# 미니 크래프트 (MiniCraft) 🧱

인터넷 연결 없이 브라우저에서 바로 실행되는 마인크래프트 스타일 복셀 게임입니다.
단일 HTML 파일로 제작되어 외부 라이브러리, 서버, CDN이 전혀 필요 없습니다.

## 실행 방법

1. `index.html` 파일을 다운로드합니다.
2. 파일을 더블클릭하거나 브라우저(Chrome, Edge, Firefox 등)로 열면 바로 실행됩니다.

별도 설치 과정이 없습니다.

## 조작법

| 동작 | 키 |
|------|------|
| 이동 | W A S D |
| 점프 | Space |
| 질주 | Shift |
| 블록 파괴 | 마우스 왼쪽 클릭 |
| 블록 설치 | 마우스 오른쪽 클릭 |
| 블록 선택 | 숫자 키 1~9 또는 마우스 휠 |
| 비행 모드 | F (Space: 상승, Shift: 하강) |
| 마우스 시점 | 게임 화면 클릭 후 이동 (ESC: 일시 정지) |

## 특징

- 절차적 지형 생성 (들, 산, 호수, 모래사장, 나무)
- 블록 파괴/설치 (잔디, 흙, 돌, 조약돌, 판자, 원목, 나뭇잎, 모래, 벽돌)
- 중력·충돌 물리, 수영, 비행 모드
- 물 반투명 렌더링, 수중 안개 효과
- 선택한 블록 하이라이트, 거리 안개, 핫바 UI

## 기술 사항

- 순수 WebGL + 바닐라 자바스크립트 (의존성 없음)
- 128×128×48 복셀 월드, 16×16 청크 단위 메싱
- 절차적 텍스처 아틀라스 (프로그램이 직접 픽셀을 그려 생성)
- DDA 복셀 레이캐스트, AABB 충돌 해결
